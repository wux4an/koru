# Fixture web para la futura prueba Android

Estos archivos no se empaquetan todavía. Cuando exista el APK builder, se copiarán
a `assets/www/` y permitirán probar CSS, imagen SVG, JavaScript, navegación y modo
offline. No tienen dependencias externas, pero su renderizado Android aún no se
ha probado. No son evidencia de funcionamiento del WebView experimental.
