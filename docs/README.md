# Documentación de koru

Para crear una app Android con koru, empieza por la [documentación de uso](https://koru.js.org/es/).

- [Primera app](https://koru.js.org/es/getting-started/): instala koru, crea un proyecto y pruébalo en Android.
- [Proyecto web existente](https://koru.js.org/es/existing-project/): empaqueta la salida de tu frontend.
- [API JavaScript](https://koru.js.org/es/plugins/): datos del dispositivo, almacenamiento y acciones de Android.
- [Distribución](https://koru.js.org/es/distribution/): comparte un APK y prepara actualizaciones.
- [Solución de problemas](https://koru.js.org/es/troubleshooting/): ayuda con builds, instalación y plugins.
